# Universal Animation Library

- Asset: Universal Animation Library, Standard edition
- Author: Quaternius
- Official source: https://quaternius.com/packs/universalanimationlibrary.html
- glTF mirror: https://github.com/J-Ponzo/gltf-universal-animation-library
- License: CC0 1.0 Universal

The bundled no-root-motion glTF contains the original standard-edition mannequin and 46 animation clips. Lyra plays these clips on their original skeleton and does not approximate them with hand-written joint rotations.
