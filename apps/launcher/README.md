# Launcher

Windows Python/Tkinter 图形启动器，负责管理 API 和 Worker 两个独立进程。

功能：

- 高 DPI、自适应缩放和居中窗口。
- 启动、停止、重启、状态识别和打开浏览器。
- 启动时自动检查更新，点击版本号可查看说明并执行一键升级。
- 升级时下载并校验安装包，备份后更新应用和启动器，再自动重启服务与启动器。
- 新版本启动失败时自动恢复应用、启动器和数据库备份。
- 后台线程执行耗时操作，日志通过线程安全队列更新界面。
- PID 与进程创建时间双重校验，只停止本启动器记录的进程。
- 先写入停止文件请求优雅退出，超时后才强制结束已校验的进程。
- 端口被其他程序占用时只报告错误，不结束其他程序。
- 关闭窗口时可选择停止服务或保留服务。

开发启动：

```bash
pnpm build
python main.py
```

发布版入口为 `LyraLauncher.exe`。启动器不执行依赖安装或项目构建，所有运行数据只写入 EXE 同级 `data/`。
