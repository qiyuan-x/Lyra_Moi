# AnythingLLM attribution

The Agent Engine in this package is a Lyra-specific adaptation of the tool-loop architecture used by AnythingLLM AIbitat.

Source reference:

```text
Mintplex-Labs/anything-llm
server/utils/agents/aibitat
```

AnythingLLM is distributed under the MIT License. A copy of its license is included as `LICENSE.anythingllm`.

Lyra replaces the AnythingLLM Workspace, settings, database, WebSocket and RAG integrations with Lyra-owned ports and persistent Agent checkpoints.
