# 图片生成工作区

## 目标

图片生成围绕“明确引用素材、创建任务、生成新结果、继续引用迭代”设计。系统不推断当前版本，也不限制三视图、部件拆分或其他固定流程。

Agent 和直接生成不是两个页面或两种工作模式。它们只是创建同一种图片任务的两个入口：

- Agent 对话：Agent 理解用户意图并调用图片工具创建任务。
- 新建任务：用户直接配置提示词、参考图、模型、数量和比例，不经过 Agent 改写。

## 页面结构

```text
主导航顶部：展开/收起按钮
顶部：当前项目、项目管理、默认图片模型、任务状态
对话栏：新建、切换、重命名和删除对话
左侧：可收起的上传素材和生成图片
中间：按任务显示输入素材、执行节点和生成结果
右侧：Agent 对话和执行状态
底部：Agent 对话输入框
```

主导航和素材栏的收起状态保存在浏览器本地。

## 项目

项目是完整的数据隔离边界。顶部项目选择器用于快速切换，项目管理支持创建、重命名、修改说明和归档。

每个项目拥有独立的对话、任务、上传素材和生成图片。切换项目后，工作区不会显示其他项目的内容。供应商连接和 API Key 是应用级配置，不随项目复制。

项目文件保存在：

```text
data/projects/<project-id>/
├─ uploads/images
├─ uploads/thumbnails
├─ generated/images
├─ generated/thumbnails
└─ temp
```

旧版 `data/blobs` 和 `data/thumbnails` 中已有的素材会在服务启动时复制到所属项目目录并更新数据库引用。迁移可重复执行，不覆盖已有文件。

## 图片迭代

1. 上传图片或从素材栏选择图片。
2. 使用 Agent 输入框说明需求，或点击“新建任务”直接配置。
3. 被引用图片显示“图1、图2”等顺序标记，任务提交后保持顺序。
4. 任务节点显示提示词摘要、来源、尝试次数和执行状态。
5. 生成结果显示在任务右侧，并进入“生成图片”分类。
6. 单击任意素材或结果可以继续引用到下一次 Agent 对话。

所有修改都生成新素材，原素材保持不变。

## 直接任务和重新创建

“新建任务”打开独立配置层，包含：

- 提示词。
- 图片供应商和图片模型。
- 生成数量。
- 图片比例。
- 有序参考图的添加、移除和排序。

直接任务使用用户填写的提示词，不调用 Agent 优化提示词。顶部当前选择的图片供应商和模型同时作为新建任务的初始值和 Agent 图片工具的本次执行模型；设置页中的默认供应商和模型用于页面首次进入时初始化。

已提交任务不原地修改。任务完成或失败后可以点击“编辑并重新创建”，系统复制原任务的提示词、模型、数量、比例和参考图到配置层；再次提交会创建新任务，旧任务和来源关系保持不变。

Agent 创建的任务和直接创建的任务都绑定当前对话并显示在同一工作区。对话是任务分组，不限制任务的自然语言内容。

## 素材

上传素材和生成图片使用同一素材数据模型，但在界面和文件目录中明确分开：

- 上传素材：用户上传的参考图。
- 生成图片：任务输出。

左侧素材栏和素材库都按这两个来源分组。底层文件使用内容寻址存储；普通生成结果仍保留独立素材记录，重复上传按下方规则复用或改名。

左侧图片栏保留快速缩略图，并提供“选择引用”按钮。按钮打开可搜索、按来源筛选和多选的图片选择器，避免项目图片较多时在窄侧栏中查找。已选图片继续按“图 1、图 2……”显示引用顺序。

上传素材按当前项目和原文件名检查重复：同名且内容相同的文件直接复用已有素材；同名但内容不同的文件自动使用“名称 (2)”等新名称，不覆盖历史任务引用的不可变素材。

## 供应商设置

三个能力使用独立连接，不共享 API Key：

- LLM：ChatGPT、Gemini、DeepSeek、OpenAI 兼容。
- AI 生图：GPT、Gemini、OpenAI 兼容。
- AI 建模：Meshy、混元、Tripo；单图建模任务由独立 Model Worker 执行。

连接名称、接口格式、基础 URL、启用状态和 API Key 修改后自动保存，不提供保存按钮。
OpenAI 兼容连接填写域名根地址时自动规范为 `/v1`，避免模型列表请求落到错误的 `/models` 地址。

连通性测试执行以下步骤：

1. 保存表单中的最新配置。
2. 使用最新 API Key 请求供应商模型列表。
3. 根据连接能力过滤模型；LLM 连接排除生图模型，生图连接只保留已识别的生图模型。
4. 自动把过滤后的模型同步到当前供应商列表。
5. 用户通过供应商、模型两个下拉框指定默认执行模型，不再逐个点击“添加模型”。

同一能力可以同时启用多个供应商。图片生成工作区和设置页都使用“供应商 + 模型”两级选择，切换供应商后只显示该供应商的可用模型。每种能力只保存一个默认模型，默认供应商由该模型所属连接确定。

供应商列表的操作列使用三点菜单。未配置项提供“配置”，已配置项提供“修改配置”和“删除供应商”；供应商删除不放在连接详情页。API Key 清除按钮位于密钥输入框右侧，小屏下自动换行。

API Key 只保存到运行数据目录中的 `data/config/.env`，前端只显示是否已保存及掩码。
成功和自动保存提示显示约三秒后自动消失；错误提示保留，便于排查。

## 通知

普通图片引用不显示通知，选择状态由图片边框、顺序标记和输入框附件体现。

全局通知位于顶部栏下方，最多三条，支持手动关闭和重复合并。设置连接错误优先在设置表单内显示；生成进度由图片加载卡片和任务抽屉显示。

桌面端主菜单和素材栏可分别收起，主菜单折叠按钮位于导航顶部。小于 640 px 时主菜单切换为底部导航，素材分组横向排列，任务配置和项目管理改为单列布局，并避免页面横向滚动，适配 Android 浏览器。
